Detailed Description

Walk around a city block while it is ray traced on the CPU (IS F311 Computer Graphics project).

Window and controls follow the Assignment 2 app (GLFW, mouse look, WASD). The image is traced on the CPU with pthreads, one row at a time, and shown as a texture on a full-window quad.

Build: use the Makefile in the project root (make). It uses GLFW or FreeGLUT, whichever is installed. By hand, pass -DUSE_GLFW (GLFW 3) or -DUSE_FREEGLUT (FreeGLUT): macOS (GLFW): cc -std=c11 -O2 -pthread -DUSE_GLFW -I$(brew –prefix glfw)/include -o live live.c -L$(brew –prefix glfw)/lib -lglfw -framework OpenGL -lm Linux (GLFW): cc -std=c11 -O2 -pthread -DUSE_GLFW -o live live.c -lglfw -lGL -lm Linux (FreeGLUT): cc -std=c11 -O2 -pthread -DUSE_FREEGLUT -o live live.c -lglut -lGL -lm Windows (GLFW): gcc -std=c11 -O2 -pthread -DUSE_GLFW -o live.exe live.c -lglfw -lopengl32 -lgdi32 -lm (MSYS2 MINGW64 shell) Run: ./live interactive window ./live –snapshot out.bmp render one frame at 640x360, no window ./live –bench 60 walk 60 frames along a fixed path, print FPS, no window

Controls: mouse look, W/A/S/D walk and strafe, Shift run, scroll or +/- zoom, R reset, 1/2/3 render size 320x180 / 480x270 / 640x360, Esc quit.

◆ traverse()

int traverse ( V3 o,
V3 d,
double tmax,
int any,
double * tout,
V3 * nout )
static

Finds what a ray hits by walking the grid (2D form of Amanatides and Woo's voxel traversal).

The global objects are tested first. The ray is then clipped to the grid square, and the cells it crosses are visited in order: each step moves along the axis whose next boundary (tMax) is nearest and adds that axis's tDelta. The walk stops when the next boundary is beyond the best hit so far, which keeps the nearest hit correct even for objects that span several cells.

Parameters
oRay origin.
dNormalised direction.
tmaxOnly hits closer than this count (light distance for shadow rays).
any0: find the nearest hit. 1: return at the first hit, skipping emissive objects (shadow test).
[out]toutHit distance (any == 0 only).
[out]noutHit normal (any == 0 only).
Returns
Index of the object hit, or -1.
